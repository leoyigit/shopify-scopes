Select all scopes

One click ticks every scope in Shopify's Select scopes list and presses Done. If the list is closed, it opens it first.

Any computer, any browser: the bookmark

  1. Drag this button to your bookmarks bar (show the bar with ⌘⇧B or Ctrl+Shift+B):
    ✓ Select all scopes
    Loading the latest version…
  2. Open your app's page in Shopify, the one with the Scopes section (for example Dev Dashboard → Create an app).
  3. Click the bookmark.

Can't drag? , add a new bookmark, and paste it as the address.

On a Mac: a command and a keyboard shortcut

Run it from Terminal or with one key, without clicking anything. Paste this into Terminal; the installer guides you through the rest:

curl -fsSL https://raw.githubusercontent.com/leoyigit/shopify-scopes/main/install.sh | bash
The bookmark only works on Shopify pages and only touches the scopes list. Nothing is sent anywhere. Source, details and help: github.com/leoyigit/shopify-scopes
